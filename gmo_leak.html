1. 黑客入侵手段与完整攻击链路还原 Hack Attack Chain & Infiltration Mechanism

安全研究人员对攻击者公开的日志样本（如 samples.zip 中的 INFO.txt）及受损账户表现进行逆向分析后，还原了黑客实现此次攻击的**全套技术手段与入侵链条**：

① 初始突破口：VPS 云端基础设施沦陷

  • 服务定位：受害服务为 GMO 旗下的“お名前.com デスクトップクラウド”，广泛用于 FX 外汇自动交易（MetaTrader 挂机）。
  • 突破手段：攻击者通过扫描暴露在公网上的 RDP（远程桌面，默认端口 3389）服务，利用弱口令、已知系统漏洞或凭证泄露，成功获取了云端虚拟桌面（VPS）的最高管理员权限（Administrator）。

② 核心杀招：RDP 本地磁盘映射“反向渗透”

  • 漏洞根源：用户在自己家中的电脑上使用 Windows 远程桌面连接云端 VPS 时，默认勾选了“将本地磁盘（如 C 盘、D 盘）挂载到远程服务器”（RDP 配置文件参数：drivestoredirect:s:*）。
  • 反向渗透：攻击者掌控 VPS 后，顺着这个挂载通道，直接反向访问并穿越到了用户家中的物理电脑硬盘（路径表现为 \tsclient\c\）。

③ 自动化脚本洗劫与金融破坏手段

  • 本地文件批量窃取：攻击者编写自动化脚本，在 10 月 14 日深夜静默运行，短短 20 多分钟内从用户本地电脑中检索并打包带走了 4,352 个敏感文件，包括个人证件照片、财务表格、浏览器 SQLite 密码数据库及完整历史访问记录（History）。
  • FX 终端恶意爆仓（Financial Sabotage）：攻击者发现用户挂在虚拟桌面上的 MT4 / MT5 外汇交易软件处于登录状态且保存了明文密码，随即编写批量脚本操控终端，故意执行大量高频、满仓的反向极端交易，强行将 1,260 个账户的账面资金迅速亏空清零。
  • 心理恐慌与精神羞辱战术：将盗取的用户隐私与浏览器书签/历史交叉比对，为受害者撰写“个人生活画像”，并通过每日中午 12 点“挤牙膏”式公开一人信息的方式，对受害者及其亲友进行持续的精神虐待与社会工程学施压。

2. 攻击者基础设施与网络指纹 Infrastructure & Network Forensics

研究人员通过对泄密网站进行网络测绘（Shodan/Censys）与 DNS 追踪，还原了攻击者的底层隐藏架构：

① 域名与关联邮箱命名规律

  • 泄密站点域名：coronamng[.]store（直接注册于明网，未使用 Tor 暗网 .onion 域名，意在降低普通受害者的访问门槛以制造更大恐慌）。
  • 关联勒索邮箱：boromngap@gmail.com（现已被 Google 封停）。
  • 命名特征：邮箱前缀 boromngap 与网站域名 coronamng 均包含 mng 字样（疑似 Management 的缩写，或特定黑客工具/团伙的内部代号）。

② 匿名托管与“7,130+站点”掩护

  • 注册与托管商：海外服务商 Namecheap, Inc.。攻击者利用其支持加密货币（BTC）支付及免费提供 Withheld for Privacy（WHOIS 隐私保护）的特性，抹去了实名注册信息。
  • 服务器环境：运行于 LiteSpeed Web 服务器，采用廉价共享主机（Shared Hosting）。
  • 人海掩护策略：经反向 IP 查询，该服务器同一 IP 地址下同时挂载了 超过 7,130 个 其他网站，攻击者借此规避基于单一 IP 的封锁并干扰溯源。

3. 网站源码拆解与恶意追踪机制 Source Code Audit & Tracking Trap

独立开发者下载并审计了该网站的全部前端 HTML5 源码与脚本，发现了极高风险的监控后门与母语破绽：

① 站点目录与页面结构

  • /index.html：主勒索声明、倒计时器、所谓“已破坏账户比例（声称破坏17%、约77亿日元）”及挑拨用户向 GMO 施压的言论。
  • /timeline.html：记录从 10 月 21 日以来的威胁邮件发送、跨国催促电话及最后通牒时间线。
  • /data.html & /samples.zip：提供 25 张威胁邮件与系统截图、2 份 Excel 表格（列有 1,260 个受损 MT4/MT5 外汇账户）及 10 台 VPS 的窃密日志样本。
  • /plan.html：后续破坏计划、暗网兜售预告及赎金要求（从最初邮件索要 5,000 万美元降至网站公开要求的 100 万美元）。
  • /victim1.html（10月27日 12:00 新增）：“被害者 第1号”个人隐私全曝光独立页面。

② 隐蔽追踪信标（track.php）触发机制

<!-- 嵌于网页 HTML 底部的 1x1 像素隐蔽追踪代码 --> <img src="track.php" width="1" height="1" alt="" style="display:none;" />
  • 收集维度：当浏览器加载网页时会自动请求 track.php，后端随即记录访问者的 真实 IP 地址、User-Agent（操作系统版本、浏览器型号、设备类型）、HTTP Referer（来源页面）以及精确访问时间戳。
  • 战术意图：攻击者借此监控日本警方、GMO 安全团队是否在调查该站点，同时筛选出因恐慌而高频刷新页面的受害者 IP。

③ JavaScript 源码中的“母语破绽”（accounts.js 等）

  • 网站前端展示的日语威胁信虽然语法通顺，但带有明显的欧美语言翻译腔（疑似 DeepL 翻译或 AI 生成）。
  • 核心破绽：研究人员在检视负责渲染受损账户数据的 JavaScript 脚本源码（如 accounts.js）时，发现了开发者遗留的代码注释（Comments）。这些注释使用了极其地道、符合日本本土程序员习惯的自然日语词汇与语法，直接戳穿了其“纯外籍黑客团伙”的伪装。
